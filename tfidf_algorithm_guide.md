# ✂️ TF-IDF Algorithm Documentation (AgileMindTools: Task_Split)

## 1. Overview
In the **Task_Split** system, the **TF-IDF** (Term Frequency-Inverse Document Frequency) algorithm is used as a "Keyword Highlighter" to identify the most important technical and functional terms in a task description. This helps the AI understand the core requirements and create relevant subtasks.

---

## 2. Core Concepts (The Math)

The algorithm calculates a "Weight Score" for every word in a task based on two key metrics:

### **A. Term Frequency (TF)**
Measures how often a word appears in a **specific** task description.
*   **Logical Goal**: Focus on what the task is *about*.
*   **Formula**: `Count of word / Total words in task`

### **B. Inverse Document Frequency (IDF)**
Measures how rare a word is across **all** tasks in the project.
*   **Logical Goal**: Penalize common words (e.g., "is", "the", "update") and reward technical terms (e.g., "OAuth", "API", "Database").
*   **Formula**: `Log( Total Tasks / (1 + Tasks with word) )`

### **C. Final Score (TF-IDF)**
The score is the product of TF and IDF:
*   `Final Score = TF * IDF`

## 3. Algorithm Pseudocode (Sufocode)

### **A. Training Phase (Learning context)**
This part happens when the system first scans historical tasks.

```pseudocode
ALGORITHM Train_TF_IDF:
    INPUT: Corpus (All existing tasks in project)
    
    1. Collect all unique words across all tasks (Vocabulary)
    2. Filter out "Stop Words" (e.g., "a", "the", "and")
    
    FOR EACH word in Vocabulary:
        a. Count how many tasks contain this word.
        b. Calculate IDF = LOG(Total_Tasks / (1 + Tasks_with_word))
        c. Store IDF score for this word.
    ENDFOR
END ALGORITHM
```

### **B. Extraction Phase (Analyzing a new task)**
This part happens when you split a new backlog item.

```pseudocode
ALGORITHM Extract_Keywords:
    INPUT: New_Task_Description
    
    1. Split description into individual words (Tokens)
    2. KEYWORD_SCORES = {}
    
    FOR EACH word in Tokens:
        a. Calculate TF = Count_of_word / Total_words_in_description
        b. SCORE = TF * GET_STORED_IDF(word)
        c. Add word and SCORE to KEYWORD_SCORES
    ENDFOR
    
    3. Sort KEYWORD_SCORES by HIGHEST score first
    4. RETURN TOP 10 keywords
END ALGORITHM
```

---

## 4. Usage in Task Splitting
The results of this algorithm are used in three critical ways:

1.  **Tag Prediction**: The highest-scoring keywords define the best tags for subtasks.
2.  **Duplicate Detection**: If two subtasks have identical or very high TF-IDF "Vector Distance," one is flagged as a duplicate.
3.  **Priority Estimation**: Keywords like "Security," "Critical," or "Core" are given higher weights to suggest a "High" status.
